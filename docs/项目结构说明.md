# AJOU 云服务商城 · 项目结构说明



## 技术栈与运行方式

- **语言/框架**：Java 17 · Jakarta Servlet 6 · JSP + JSTL · 原生 JDBC · MySQL
- **构建**：Maven，`mvn clean package` → `target/ROOT.war`（`finalName=ROOT`，部署为根路径）
- **运行**：Tomcat 10.1/11 + JDK 17+，库 `ajou_admin`
- **分层**：
  - 前台 = 公开 JSP + jQuery（`assets/js/*.js`）调 JSON 接口（`/api/*` 与兼容 PHP 的 `*.php`）
  - 后台 = `/admin/*` 的 JSP，单 Servlet 按 `action` 分发（Model 2），`AdminAuthFilter` 拦截登录
  - 数据层 = 每表一个 DAO（全程 `PreparedStatement`），统一经 `DbUtil` 取连接
  - 配置 = `app_configs` 表（支付宝/SMTP/AI/Google/站点等 key-value）

## 数据库表一览（库 `ajou_admin`，共 12 张）

| 表 | 用途 | 对应 Java 实体/DAO |
|----|------|---------------------|
| `admins` | 后台管理员账号 | Admin / AdminDao |
| `users` | 前台顾客账号（邮箱/Google） | User / UserDao |
| `auth_tokens` | 前台登录令牌 | AuthTokenDao |
| `email_codes` | 邮箱验证码（注册/登录/找回） | EmailCodeDao |
| `product_specs` | 云产品规格 SKU | ProductSpec / ProductSpecDao |
| `cloud_orders` | 订单 + 云实例 | CloudOrder / CloudOrderDao |
| `app_configs` | 系统配置（支付宝/SMTP/AI/Google/站点等） | AppConfig / AppConfigDao |
| `home_recommends` | 首页热门产品推荐卡片 | HomeRecommend / HomeRecommendDao |
| `dynamic_posts` | 产品动态文章（CMS） | DynamicPost / DynamicPostDao |
| `dynamic_categories` | 产品动态分类 | DynamicCategory / DynamicCategoryDao |
| `community_questions` | 开发者社区问答 | CommunityQuestion / CommunityQuestionDao |
| `community_replies` | 社区问答回复 | CommunityReply / CommunityReplyDao |

> 支付宝商户参数（App ID/私钥/公钥）来自后台「系统设置」→ 存 `app_configs` 的 `alipay` 分组。
